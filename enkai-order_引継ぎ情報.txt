【Laravel「enkai-order」開発 引継ぎ情報】

■ 目的
学校のWeb開発実習で作成しているLaravelアプリ。
宴会・グループ注文を、幹事がまとめて管理できるようにするアプリ。
参加者が注文を登録し、幹事が確認・承認・差し戻しできる。

■ 開発環境
- プロジェクト名：enkai-order
- WSL/Linuxパス：/home/tak/enkai-order
- Laravel：13.16.1
- PHP：8.5.7
- Docker / Laravel Sail 使用
- GitHub：https://github.com/ivyc251018takata/laravel.git
- ブランチ：main

■ 基本設計
- ログイン機能は作らない。
- 幹事は organizer_token Cookie で識別。
- 参加者は participant_id Cookie で識別。
- join_code は宴会参加用の6文字コード。
- 参加者は join_code + ニックネームで参加。
- organizer_token Cookieは1年、participant_id Cookieは30日保存。
- 「新しい宴会を作る」と「以前の宴会に戻る」は別操作にする。
- 不要なDB変更は避ける。

■ DB

parties
- id
- name
- join_code（6文字、unique）
- organizer_token（64文字、unique）
- table_number（nullable）
- memo（nullable）
- created_at
- updated_at

participants
- id
- party_id（FK、cascadeOnDelete）
- nickname
- memo（nullable）
- created_at
- updated_at

orders
- id
- participant_id（FK、cascadeOnDelete）
- item_name
- quantity
- unit_price（nullable）
- memo（nullable）
- status（0=未確認、1=承認済み、2=差し戻し）
- reject_reason（nullable）
- created_at
- updated_at

■ Model

Party.php
- fillable：name, join_code, organizer_token, table_number, memo
- participants()：hasMany(Participant::class)

Participant.php
- party()：belongsTo(Party::class)
- orders()：hasMany(Order::class)

Order.php
- fillable：participant_id, item_name, quantity, unit_price, memo, status, reject_reason
- participant()：belongsTo(Participant::class)

■ Party作成
app/Http/Requests/StorePartyRequest.php
- name：required/string/max:255
- table_number：nullable/string/max:255
- memo：nullable/string

app/Http/Controllers/PartyController.php
- Party::create()で宴会を作成
- join_code：strtoupper(Str::random(6))
- organizer_token：Str::uuid()
- 作成後 organizer_token をCookie（1年）に保存

■ Participant
app/Http/Controllers/ParticipantController.php
- create()：参加画面
- store()：
  - join_codeを大文字化してParty検索
  - 存在しなければ「参加コードが存在しません。」
  - Participant作成
  - participant_id Cookieを30日保存
- organizerIndex()：
  - organizer_token CookieからParty取得
  - そのPartyの参加者一覧を取得
  - participants.organizerを表示

■ Order
app/Http/Controllers/OrderController.php

参加者側：
- create()：注文登録画面
- index()：participant_id Cookieの注文一覧
- store()：注文登録
- edit()：自分の注文だけ編集可能
- update()：自分の注文だけ更新可能。更新時status=0、reject_reason=null
- destroy()：自分の注文だけ削除可能

入力ルール：
app/Http/Requests/StoreOrderRequest.php
- item_name：required/string/max:255
- quantity：required/integer/min:1
- unit_price：nullable/integer/min:0
- memo：nullable/string

幹事側：
- organizerIndex()
  - organizer_tokenでParty確認
  - Partyのparticipants取得
  - Partyに属するordersを取得
  - participantとのリレーションをwith
  - totalAmount：全注文合計
  - approvedAmount：status=1の注文合計
  - participantTotals：参加者ごとの注文合計
  - unpricedOrders：unit_price未設定の注文
  - 次の候補として状態件数も追加予定
- organizerParticipantOrders()
  - 特定参加者の注文だけ表示
  - organizerのPartyに属しているか確認
  - このメソッドでは$participantsを使わない
- approve()
  - status=1、reject_reason=null
- reject()
  - status=2、reject_reasonを保存

■ ルート

GET / → home
GET /parties/create → parties.create
POST /parties → party.store
GET /participants/create → participants.create
POST /participants → participants.store
GET /orders/create → orders.create
POST /orders → orders.store
GET /orders → orders.index
GET /orders/{order}/edit → orders.edit
PUT/PATCH /orders/{order} → orders.update
DELETE /orders/{order} → orders.destroy

幹事：
GET /organizer/participants → organizer.participants.index
GET /organizer/orders → organizer.orders.index
POST /organizer/orders/{order}/approve → organizer.orders.approve
POST /organizer/orders/{order}/reject → organizer.orders.reject
GET /organizer/participants/{participant}/orders → organizer.participants.orders

例：
<a href="{{ route('organizer.orders.index') }}">

</a>

<a href="{{ route('organizer.orders.index') }}">

■ 既知の問題
過去に
Undefined variable $participants
app/Http/Controllers/OrderController.php:176
URL：/organizer/participants/14/orders
が発生。

原因はorganizerParticipantOrders()で$participantsを使っていたこと。
現在はorganizerParticipantOrders()では$party、$participant、$ordersだけをViewに渡す。
participants.organizer側でのみ$participantsを使う。

- 既存機能を壊さない。

- エラーが出た場合は、エラーメッセージとファイル・行番号を確認してから修正する。
- 現在の全ファイル内容はこの引継ぎ情報だけでは保証されないため、実際の修正前に必要なファイルを確認する。
